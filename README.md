Entreprise de nettoyage commercial (bureaux, commerces, garderies, pharmacies) lancée par **Ons Ben Temarzit** et **Ghassen Ben Hassan**.

Ce dépôt contient **deux propositions** d'identité. Le nom final sera choisi ensemble.

| | Brivo Clean | Octo Clean |
|---|---|---|
| Style | Sobre, professionnel | Sympathique, mémorable |
| Symbole | Goutte d'eau + étincelle | Pieuvre aux huit bras |
| Registre de l'Ontario | Aucun « Brivo Clean » trouvé | Aucun « Octo Clean » trouvé (« Octopus Cleaning », Toronto, est inactive) |
| Domaine | `brivoclean.ca` libre (17,09 $/an) | `octoclean.ca` libre (17,09 $/an) |

Vérifications faites le 13 octobre 2026. À refaire juste avant l'enregistrement et l'achat du domaine.

## Mettre le site en ligne avec GitHub Pages

1. **Settings → Pages**
2. Source : **Deploy from a branch**, branche `main`, dossier `/ (root)`
3. Le site sera disponible à `https://ghassen1956.github.io/projet-nettoyage/`

Attention : avec un compte GitHub gratuit, GitHub Pages ne fonctionne que si le dépôt est **public**.

Une fois le nom choisi, on gardera seulement le dossier retenu et on reliera le domaine `.ca` au site.
